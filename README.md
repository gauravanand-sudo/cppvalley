# cppvalley

The HFT Core Systems home for the cppvalley YouTube channel.

## Product

- 96 evidence-driven episodes
- 9 sequential phases
- 4 flagship systems projects
- one public tick-to-trade capstone

The website is intentionally focused: YouTube builds the mental model; cppvalley.com carries the curriculum, source evidence, benchmark methodology, and project trail.

## Development

```bash
npm ci
npm run dev
```

Validate a production change with:

```bash
npm run lint
npm run build
```
