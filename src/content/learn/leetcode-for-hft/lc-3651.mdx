## Problem (Re-stated)
You have an `m x n` grid. Start at `(0,0)` with cost `0`, reach `(m-1,n-1)`.

Moves:
- **Normal:** right/down, pay **value of destination cell**
- **Teleport (≤ k times):** from `(i,j)` to **any** `(x,y)` with `grid[x][y] ≤ grid[i][j]`, cost `0`

Return minimum total cost.

---

## How to Think in an Interview (Slow, Intuitive, Step-by-Step)

### 1) First: ignore teleports (anchor your brain)
If teleports didn't exist, you only move **right/down** and pay destination cell value.

That's the classic **min cost path in a grid** with a DAG structure *(because you never go left/up).* 

So you'd do DP:

- `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`
- Start cell `(0,0)` cost is `0` (you don't pay for the start)

✅ This gives you a solid baseline mental model.

---

### 2) Now add teleport: what fundamentally breaks?
Teleport lets you jump anywhere (including "backwards") with **0 cost**, as long as the destination cell value is `≤ current value`.

**This destroys the "DAG only" property.**
This is a very important realization. We now understand that simple DP no longer works. Now this not DAG only. This has become a graph.
And we need to find the shortest path.

✅ New mental model: **this is a shortest path problem on a graph.**

---

### 3) Convert to a graph in your head (key unlock)
Treat each cell as a node.

Edges:
1. Right: `(i,j) -> (i,j+1)` cost `grid[i][j+1]`
2. Down: `(i,j) -> (i+1,j)` cost `grid[i+1][j]`
3. Teleport: `(i,j) -> (x,y)` cost `0` if `grid[x][y] ≤ grid[i][j]` but at most `k` times total.

All edges are **non-negative** (0 or positive), so shortest path suggests **Dijkstra**.

---

### 4) Handle "at most k teleports" (standard interview trick)
*When there's a limited resource, you add it to the state.* This is a very important template. So keep in mind from next time
whenever you see a limited resources, it signifies that we add that variable to the state.

State becomes:

- **(cell, usedTeleports)**

Create layers:
- Layer 0 = used 0 teleports
- Layer 1 = used 1 teleport
- ...
- Layer k

Transitions:
- Right/down stay in the same layer
- Teleport goes from layer `t` to `t+1`

✅ Now it's "Dijkstra on a layered graph".

This is already a correct approach conceptually.

---

### 5) Why not jump to data structures immediately?
Because the *first* job is to show:
1. Correct modeling (layered state graph)
2. Correct algorithm choice (Dijkstra because weights ≥ 0)
3. Then optimize the bottleneck

Interviewers care about your reasoning path.

A great "first 60 seconds" line:
> "I'll run Dijkstra on states `(i,j,t)` where `t` teleports used. Normal moves cost destination value; teleport is 0-cost to any cell with value ≤ current, moving to `t+1`."

---

### 6) Find the real bottleneck
Naively, teleport from one cell can go to **O(mn)** cells.
Total states are about `mn*(k+1)`.

Naive teleport expansion becomes too slow.

So the real question:
✅ "How do I apply teleport transitions efficiently?"

---

### 7) Key observation: teleport depends only on cell values
Teleport rule from value `A`:
> You can reach **all cells with value ≤ A** at cost 0.

This depends only on **values**, not position.

So from a state with current distance `d` at value `A`, in the next layer:
- every cell with value `≤ A` can get candidate distance `d`

That is a **batch relaxation** over a set of cells.

---

### 8) The optimization idea (before any DS name)
If you sort all cells by their `grid` value, then
"cells with value ≤ A" become a **prefix** of this sorted list.

So teleport becomes:
- "apply `dist = min(dist, d)` to a prefix range"

And Dijkstra needs:
- repeatedly pick the smallest unprocessed tentative distance

So we want a structure that supports:
1. prefix `chmin` updates
2. extract global minimum

That's why a segment tree (lazy range-chmin + global min) works.

## C++ Solution (Optimized Dijkstra + Segment Tree)

<div className="max-h-[600px] overflow-y-auto">

```cpp
#include <bits/stdc++.h>
using namespace std;

class SegTreeMinAssign {
public:
    int n;
    const long long INF = (long long)4e18;
    vector<long long> mn, lazy;

    SegTreeMinAssign() : n(0) {}
    SegTreeMinAssign(int n_) { init(n_); }

    void init(int n_) {
        n = n_;
        mn.assign(4*n, INF);
        lazy.assign(4*n, INF);
    }

    long long getMin() const {
        if (n == 0) return INF;
        return mn[1];
    }

    void rangeChmin(int ql, int qr, long long val) {
        if (n == 0 || ql > qr) return;
        rangeChmin(1, 0, n-1, ql, qr, val);
    }

    pair<int,long long> extractMin() {
        if (n == 0) return {-1, INF};
        if (mn[1] ≥ INF) return {-1, INF};
        return extractMin(1, 0, n-1);
    }

private:
    inline void apply(int p, long long v) {
        mn[p] = min(mn[p], v);
        lazy[p] = min(lazy[p], v);
    }

    void push(int p) {
        if (lazy[p] ≥ INF) return;
        apply(p<<1, lazy[p]);
        apply(p<<1|1, lazy[p]);
        lazy[p] = INF;
    }

    void pull(int p) {
        mn[p] = min(mn[p<<1], mn[p<<1|1]);
    }

    void rangeChmin(int p, int l, int r, int ql, int qr, long long val) {
        if (qr < l || r < ql) return;
        if (ql ≤ l && r ≤ qr) {
            apply(p, val);
            return;
        }
        push(p);
        int m = (l + r) >> 1;
        rangeChmin(p<<1, l, m, ql, qr, val);
        rangeChmin(p<<1|1, m+1, r, ql, qr, val);
        pull(p);
    }

    pair<int,long long> extractMin(int p, int l, int r) {
        if (l == r) {
            long long val = mn[p];
            mn[p] = INF;
            lazy[p] = INF;
            return {l, val};
        }
        push(p);
        int m = (l + r) >> 1;
        pair<int,long long> res;
        if (mn[p<<1] ≤ mn[p<<1|1]) res = extractMin(p<<1, l, m);
        else res = extractMin(p<<1|1, m+1, r);
        pull(p);
        return res;
    }
};

class Solution {
public:
    long long minCost(vector<vector<int>>& grid, int k) {
        int m = (int)grid.size();
        int n = (int)grid[0].size();
        int N = m * n;

        auto id = [&](int i, int j){ return i*n + j; };

        vector<int> val(N);
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                val[id(i,j)] = grid[i][j];

        vector<int> order(N);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b){
            if (val[a] != val[b]) return val[a] < val[b];
            return a < b;
        });

        vector<int> pos(N);
        vector<int> sortedVals(N);
        for (int i = 0; i < N; i++) {
            pos[order[i]] = i;
            sortedVals[i] = val[order[i]];
        }

        const long long INF = (long long)4e18;
        vector<vector<long long>> dist(k+1, vector<long long>(N, INF));

        vector<SegTreeMinAssign> seg(k+1);
        for (int t = 1; t ≤ k; t++) seg[t].init(N);

        struct Node {
            long long d;
            int t;
            int v;
            bool operator>(const Node& o) const { return d > o.d; }
        };
        priority_queue<Node, vector<Node>, greater<Node>> pq;

        int start = 0;
        int target = id(m-1, n-1);

        dist[0][start] = 0;
        pq.push({0, 0, start});

        auto upperIndexForValue = [&](int A) -> int {
            int up = (int)(upper_bound(sortedVals.begin(), sortedVals.end(), A) - sortedVals.begin()) - 1;
            return up;
        };

        auto anySegHasWork = [&]() -> bool {
            for (int t = 1; t ≤ k; t++)
                if (seg[t].getMin() < INF) return true;
            return false;
        };

        while (!pq.empty() || anySegHasWork()) {
            long long best = pq.empty() ? INF : pq.top().d;
            int bestLayer = -1;

            for (int t = 1; t ≤ k; t++) {
                long long smin = seg[t].getMin();
                if (smin < best) {
                    best = smin;
                    bestLayer = t;
                }
            }

            if (bestLayer != -1) {
                auto [idx, d] = seg[bestLayer].extractMin();
                if (idx == -1) continue;
                int vtx = order[idx];
                if (d < dist[bestLayer][vtx]) {
                    dist[bestLayer][vtx] = d;
                    pq.push({d, bestLayer, vtx});
                }
                continue;
            }

            auto cur = pq.top(); pq.pop();
            long long d = cur.d;
            int t = cur.t;
            int vtx = cur.v;
            if (d != dist[t][vtx]) continue;

            if (vtx == target) return d;

            int i = vtx / n;
            int j = vtx % n;

            if (j + 1 < n) {
                int nv = id(i, j+1);
                long long nd = d + grid[i][j+1];
                if (nd < dist[t][nv]) {
                    dist[t][nv] = nd;
                    pq.push({nd, t, nv});
                }
            }
            if (i + 1 < m) {
                int nv = id(i+1, j);
                long long nd = d + grid[i+1][j];
                if (nd < dist[t][nv]) {
                    dist[t][nv] = nd;
                    pq.push({nd, t, nv});
                }
            }

            if (t < k) {
                int up = upperIndexForValue(val[vtx]);
                if (up ≥ 0) seg[t+1].rangeChmin(0, up, d);
            }
        }

        return -1;
    }
};
```

## Explanation of the code

## Part A — What the segment tree stores

Think of an array `a[0…n−1]` (conceptually). Initially:

* `a[i] = INF` for all i.

The segment tree supports two operations:

### 1) `rangeChmin(ql, qr, val)`

For every index `i` in `[ql…qr]`:

> `a[i] = min(a[i], val)`

So it’s like “try to improve the cost” for many indices at once.

### 2) `extractMin()`

Find the index `i` with the smallest value `a[i]`, return `(i, a[i])`, and then **remove it** by setting:

> `a[i] = INF`

This is like a priority queue that also supports **range updates**.

---

## Part B — Segment tree internals (step-wise)

### Data members

* `mn[p]` = minimum `a[i]` inside the segment represented by node `p`
* `lazy[p]` = a “pending chmin value” that still needs to be applied to children

`INF` means “no value / not active”.

---

### Step 1: `apply(p, v)`

```cpp
mn[p] = min(mn[p], v);
lazy[p] = min(lazy[p], v);
```

Meaning:

* We are saying “every element in this node’s segment could be improved by `v`”.
* That immediately affects the node minimum `mn[p]`.
* And we remember it in `lazy[p]` so we can push it down later.

---

### Step 2: `push(p)`

```cpp
if (lazy[p] ≥ INF) return;
apply(p<<1, lazy[p]);
apply(p<<1|1, lazy[p]);
lazy[p] = INF;
```

Meaning:

* If node `p` has a pending update, we forward it to its children.
* After pushing, node `p` has no pending update.

**Why needed?**
Because when we go deeper (partial overlap update or extracting min), we must ensure children know all constraints that should affect them.

---

### Step 3: `pull(p)`

```cpp
mn[p] = min(mn[p<<1], mn[p<<1|1]);
```

Meaning:

* After children are updated, parent minimum is just min of children.

---

### Step 4: `rangeChmin(p, l, r, ql, qr, val)`

Cases:

1. **No overlap**

   * segment `[l…r]` is completely outside `[ql…qr]` → return

2. **Full overlap**

   * `[l…r]` fully inside `[ql…qr]` → just `apply(p, val)` and stop
     (we don’t go deeper, that’s the whole point of lazy)

3. **Partial overlap**

   * We must go deeper:

     * `push(p)`
     * recurse left and right
     * then `pull(p)`

So the segment tree keeps the correct minimum.

---

### Step 5: `extractMin(p, l, r)`

Goal: go to the leaf with the globally smallest value.

1. If `l == r` (leaf):

   * this leaf corresponds to one index
   * return its value and set it back to `INF` (removing it)

2. Otherwise:

   * `push(p)` (so children are correct)
   * compare children minima:

     * go to the child with smaller `mn`
   * after returning, `pull(p)` to fix parent minimum

So `extractMin()` is like “pop the best pending thing”.

---

## Part C — What the Solution is doing (high level)

We have a grid `m×n`, start at `(0,0)`, target `(m−1,n−1)`.

Movement allowed:

* Right
* Down

Each time you enter a cell, you pay its cost (`grid[i][j]`). (Start is 0 in this code.)

There is also an extra ability used up to `k` times (layers `t = 0..k`):

* At layer `t`, you can perform a special transition to layer `t+1` that can “activate” many nodes at once (that’s what the segment tree is for).

So we run Dijkstra on a state graph:

* state = `(t, v)` where `t` is how many specials used, `v` is a cell id.

`dist[t][v]` = minimum cost to reach cell `v` having used exactly `t` specials.

---

## Part D — Flattening and sorting cells

### Step 1: flatten 2D into 1D

```cpp
id(i,j) = i*n + j
```

### Step 2: `val[v] = grid[i][j]`

### Step 3: sort all vertices by their cell value

`order` is list of vertices sorted by `val[v]` ascending.

Then:

* `sortedVals[i] = val[order[i]]`
* `pos[v] = index of v in sorted order` (computed but not used later)

**Why sort?**
Because later we want:
“All cells with value ≤ A” → that becomes a prefix `[0…up]` in sorted order.

---

## Part E — The “upperIndexForValue” helper

```cpp
up = upper_bound(sortedVals, A) - 1
```

So:

* indices `0…up` are exactly those cells where `val[cell] ≤ A`.

---

## Part F — Two priority structures in the loop

There are TWO ways new states appear:

### 1) Normal Dijkstra edges → go into `pq`

From `(t, cell)` to right/down neighbor with extra cost.

### 2) Special edges → go into `seg[t]`

This is the interesting part.

When at `(t, vtx)` with cost `d`, if `t < k`:

```cpp
up = upperIndexForValue(val[vtx])
seg[t+1].rangeChmin(0, up, d)
```

Meaning:

> In the next layer `(t+1)`, for every cell whose value ≤ current cell value,
> we can reach it with cost at most `d` (no extra cost here).

That’s a *mass update* across many vertices → segment tree is perfect.

---

## Part G — Main loop logic (very important)

Condition:

```cpp
while (!pq.empty() || anySegHasWork())
```

So we continue as long as:

* there is normal Dijkstra work (`pq`), OR
* there are pending segment relaxations in any layer.

### Step 1: pick the globally best “next thing”

We compare:

* best cost in `pq` (top of heap)
* best cost in each `seg[t]` (their `getMin()`)

Whichever has smaller cost is processed first.
This keeps Dijkstra correctness because we always expand the globally smallest available distance.

---

### Case 1: a segment tree has the best candidate

We pop it:

```cpp
(idx, d) = seg[bestLayer].extractMin();
vtx = order[idx];
```

Recall: `idx` is in “sorted-by-value index space”, so we convert back to vertex id using `order[idx]`.

Then:

```cpp
if (d < dist[bestLayer][vtx]) {
    dist[bestLayer][vtx] = d;
    pq.push({d, bestLayer, vtx});
}
```

Meaning:

* This “bulk relaxation” becomes a real Dijkstra node.
* If it improves the distance, we accept it and push into `pq`.

So the segtree is basically generating Dijkstra states lazily.

---

### Case 2: `pq` has the best candidate

We pop:

```cpp
(d, t, vtx)
```

Skip stale entries:

```cpp
if (d != dist[t][vtx]) continue;
```

If it’s target → return answer.

Then normal moves:

* right neighbor
* down neighbor

Each move costs `grid[newCell]`.

Finally special move:
if `t < k`:

* compute `up` for `val[vtx]`
* do `seg[t+1].rangeChmin(0, up, d)`

---

## Part H — Why this is correct (short intuition)

Dijkstra needs:

* always process smallest unprocessed distance next.

Here we have two sources of “unprocessed candidates”:

* explicit ones in `pq`
* implicit ones stored in segtrees

So the code merges them by always taking the globally smallest among:

* `pq.top().d`
* `seg[t].getMin()` for all `t`

That keeps the Dijkstra invariant.

## Python Solution (Same Idea, Segment Tree)

<div className="max-h-[600px] overflow-y-auto">

```python
import heapq
import bisect

INF = 10**30

class SegTreeMinAssign:
    # Range chmin updates + extract global min (value, index)
    def __init__(self, n):
        self.n = n
        self.mn = [INF] * (4*n)
        self.lazy = [INF] * (4*n)

    def _apply(self, p, v):
        if v < self.mn[p]:
            self.mn[p] = v
        if v < self.lazy[p]:
            self.lazy[p] = v

    def _push(self, p):
        if self.lazy[p] == INF:
            return
        v = self.lazy[p]
        self._apply(p*2, v)
        self._apply(p*2+1, v)
        self.lazy[p] = INF

    def _pull(self, p):
        self.mn[p] = self.mn[p*2] if self.mn[p*2] < self.mn[p*2+1] else self.mn[p*2+1]

    def range_chmin(self, ql, qr, val):
        if ql > qr: 
            return
        self._range_chmin(1, 0, self.n-1, ql, qr, val)

    def _range_chmin(self, p, l, r, ql, qr, val):
        if qr < l or r < ql:
            return
        if ql ≤ l and r ≤ qr:
            self._apply(p, val)
            return
        self._push(p)
        m = (l + r) // 2
        self._range_chmin(p*2, l, m, ql, qr, val)
        self._range_chmin(p*2+1, m+1, r, ql, qr, val)
        self._pull(p)

    def get_min(self):
        return self.mn[1]

    def extract_min(self):
        if self.mn[1] ≥ INF:
            return (-1, INF)
        return self._extract_min(1, 0, self.n-1)

    def _extract_min(self, p, l, r):
        if l == r:
            v = self.mn[p]
            self.mn[p] = INF
            self.lazy[p] = INF
            return (l, v)
        self._push(p)
        m = (l + r) // 2
        if self.mn[p*2] ≤ self.mn[p*2+1]:
            res = self._extract_min(p*2, l, m)
        else:
            res = self._extract_min(p*2+1, m+1, r)
        self._pull(p)
        return res

def min_cost(grid, k):
    m, n = len(grid), len(grid[0])
    N = m * n

    def idx(i, j):
        return i*n + j

    val = [0] * N
    for i in range(m):
        for j in range(n):
            val[idx(i, j)] = grid[i][j]

    order = list(range(N))
    order.sort(key=lambda x: (val[x], x))
    sorted_vals = [val[x] for x in order]

    dist = [[INF] * N for _ in range(k+1)]

    seg = [None] * (k+1)
    for t in range(1, k+1):
        seg[t] = SegTreeMinAssign(N)

    start = 0
    target = idx(m-1, n-1)

    dist[0][start] = 0
    pq = [(0, 0, start)]  # (d, t, v)

    def upper_index_for_value(A):
        return bisect.bisect_right(sorted_vals, A) - 1

    def any_seg_has_work():
        for t in range(1, k+1):
            if seg[t].get_min() < INF:
                return True
        return False

    while pq or any_seg_has_work():
        best = pq[0][0] if pq else INF
        best_layer = -1

        for t in range(1, k+1):
            smin = seg[t].get_min()
            if smin < best:
                best = smin
                best_layer = t

        if best_layer != -1:
            si, d = seg[best_layer].extract_min()
            if si == -1:
                continue
            vtx = order[si]
            if d < dist[best_layer][vtx]:
                dist[best_layer][vtx] = d
                heapq.heappush(pq, (d, best_layer, vtx))
            continue

        d, t, vtx = heapq.heappop(pq)
        if d != dist[t][vtx]:
            continue
        if vtx == target:
            return d

        i, j = divmod(vtx, n)

        if j + 1 < n:
            nv = idx(i, j+1)
            nd = d + grid[i][j+1]
            if nd < dist[t][nv]:
                dist[t][nv] = nd
                heapq.heappush(pq, (nd, t, nv))

        if i + 1 < m:
            nv = idx(i+1, j)
            nd = d + grid[i+1][j]
            if nd < dist[t][nv]:
                dist[t][nv] = nd
                heapq.heappush(pq, (nd, t, nv))

        if t < k:
            up = upper_index_for_value(val[vtx])
            if up ≥ 0:
                seg[t+1].range_chmin(0, up, d)

    return -1
```

# Step 2) Sort by value → `order[]`, `sortedVals[]`
